## Narraverse 是什么

Narraverse 是为小说作者打造的写作之家 —— 一个安静的角落，让你的故事、角色与世界观一起生长。无论你在写第一章，还是经营一部长篇连载，Narraverse 都会把结构、设定与正文放在同一处，让你专注于只有你能写出的那部作品。

我们相信好的工具应当隐于幕后。每一个功能都像书桌上一件小小的乐器：轻柔、不打扰，需要时随手可及。

## 清晰地写作

**结构化的稿件管理**  
按卷与章节组织作品。追踪草稿、在场景间跳转，让项目随故事生长依旧井井有条。

**沉浸写作模式**  
除却稿件与思绪，其余一切尽数隐去。当你进入心流，界面会自动退后。

**昼夜由你**  
明暗主题随心切换，还能挑选契合心境的强调色。正午与凌晨两点，都一样舒适。

**优雅导出**  
一键把草稿变成整洁的 Markdown 或纯文本，随时分享或归档。

---

## 了解你的角色群像

**角色关系总览**  
为故事中的角色构建可视化图谱 —— 身份、性格、目标，以及他们之间的羁绊。

**场景级关系预览**  
写某一章时，即可看到哪些角色在场，他们的关系在此时此刻如何展开。

**导入与分析**  
粘贴既有文稿，Narraverse 自动识别章节切分。还可选跑角色分析，从你已写下的文字中生成关系图谱。

---

## 动笔之前、动笔之中，都能规划故事

**大纲树**  
把小说拆成卷与章节，情节演进时随时调整结构。

**规划文件**  
记录故事弧线、转折点与伏笔回收 —— 长篇笔记始终与项目绑定。

**世界观设定集**  
设定、阵营、规则与传说收录成一部始终一致的设定圣经。细节紧要时，一瞥即达。

**时间线管理**  
追踪故事中的关键事件，让时间线保持连贯。

## 你的 AI 伙伴 —— 是编辑，不是代笔

Narraverse 内置一体化的小说创作 Agent，五种模式各司其职：

| 模式 | 职责 |
| --- | --- |
| **Agent** | 续写、润色与修改稿件 —— 每一处改动都经你确认 |
| **Ask** | 只读地咨询情节、对白与技法 —— 绝不触碰你的文件 |
| **Plan** | 把故事弧线与节拍整理成规划文档 |
| **Outline** | 构建并打磨卷/章结构 |
| **Worldbook** | 组织并交叉关联设定，守住连续性 |

**每一次修改都由你拍板。**  
建议以 diff 呈现，逐行采纳或拒绝 —— 故事永远属于你。

**记忆长在你的项目里。**  
规划、大纲、设定与正文共享同一个事实来源。续写场景之前，Agent 会先读你已经写下的内容。

**有上下文的建议。**  
情节、场景与字句层面的反馈都源自你的稿件与设定 —— 建议贴合你的故事，而非通用模板。
