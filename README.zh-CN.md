## Narraverse 是什么？

Narraverse 是为小说创作者打造的书写家园——一个安静角落，让故事、角色与世界观在同一片空间里慢慢生长。无论你是写下第一章的新手，还是连载多年的老手，Narraverse 帮你把结构、设定与正文收拢在一起，让你把精力留给只有你能写的那部分。

我们相信，好的工具应当退居幕后。每一个功能都像桌边的小工具：温柔、不喧闹，需要时伸手可及。

## 安心写作

**清晰的稿件管理**  
按卷、按章组织作品，跟踪草稿状态，在场景之间自由切换，故事越长，结构越不乱。

**沉浸创作模式**  
收起多余界面，只留下正文与你的思路。进入状态后，工具会主动让路。

**日夜随心切换**  
浅色与深色主题自由切换，还可选择不同 accent 配色——午后阳光或深夜书房，都舒适。

**精美导出**  
一键导出排版良好的 Markdown 或纯文本，便于分享与归档。

---

## 读懂你的角色

**关系总览**  
用可视化图谱管理故事中的角色——身份、性格、目标，以及彼此之间的信任、合作、对立与纠葛。

**章节角色关系预览**  
写作时，当前章节出场的角色与关系会呈现在编辑器上方，帮你把握每一场戏的人际张力。

**批量导入与分析**  
粘贴已有文稿，系统自动识别章节标题与正文；也可在导入后运行角色分析，从现有文本中提取人物与关系，写入角色图谱。

---

## 边写边规划

**大纲树**  
按卷、按章搭建结构，情节变化时随时调整。

**规划文件**  
记录故事弧线、关键转折与伏笔回收——长篇构思与项目同源保存。

**世界观库**  
统一管理地点、势力、规则与 lore，设定不再散落在备忘录里。

**时间线**  
梳理故事中的关键事件，让时间线前后一致。

## AI 是编辑，不是代笔

Narraverse 内置全能型小说创作 Agent，五种模式各司其职：

| 模式 | 作用 |
| --- | --- |
| **执行** | 续写、润色、改稿——每一处修改都需你批准 |
| **提问** | 只读咨询，讨论剧情与笔力，不改动任何文件 |
| **规划** | 梳理故事弧线与节拍，写入规划文件 |
| **大纲** | 编辑卷章结构，维护大纲树 |
| **世界观** | 整理设定库，保持 lore 前后一致 |

**你批准每一处修改**  
改稿以 diff 形式呈现，逐条接受或拒绝——故事始终属于你。

**记忆活在项目里**  
规划、大纲、世界观与章节同源存储，续写前 Agent 会先查阅你的设定。

**建议有据可依**  
情节、场景、台词层面的反馈会结合当前章节与设定给出，而不是空泛模板。
