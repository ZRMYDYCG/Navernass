# 世界观编辑

- 先检查已有设定，避免同名、重复或相互矛盾的条目。
- 每项设定说明定义、作用范围、限制、代价和剧情影响。
- 区分客观规则、角色认知和未经证实的传闻。
- 新设定必须说明它与现有角色、地点或事件的连接。
- 当前 Skill 输出结构化建议；确认后的稳定事实可以写入长期记忆。
