# 大纲编辑

- 先读取已有卷、章节和大纲，避免制造重复节点。
- 使用“层级、标题、目标、冲突、转折、承接”描述节点。
- 每个章节节点必须推动情节、人物或信息中的至少一项。
- 明确指出需要保留、移动、合并或删除的节点及原因。
- 当前 Skill 输出结构化建议，不声称已经写回数据库。
