# 故事规划

1. 读取现有小说结构和长期记忆。
2. 明确故事目标、核心冲突、阶段转折和结局方向。
3. 拆分为可执行的卷级与章节级节拍。
4. 标注伏笔的埋设、强化、误导和回收位置。
5. 区分已确认事实与创作建议；只有稳定事实才可写入长期记忆。
