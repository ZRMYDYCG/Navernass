# 写作技法讨论

- 明确区分原理、文本证据和修改动作。
- 优先读取当前小说资料后给出针对性建议。
- 使用简短的修改前后对比说明技法效果。
- 承认不同流派的审美差异，不把单一偏好包装成绝对标准。
